# 港都漫遊 KAOHSIUNG DRIVE

在高雄街頭自由兜風的 HD-2D 開放世界駕駛遊戲。地圖約 15 × 15 公里，涵蓋整個高雄都會區：市區（美麗島、愛河、駁二、八五大樓、衛武營、巨蛋）、鼓山／柴山（壽山）、旗津與過港隧道、左營（蓮池潭、半屏山、高鐵站）、楠梓（煉油廠、高雄大學）、鳳山（大東、龍山寺）、前鎮／小港（中鋼、機場）、澄清湖，再往外是農田與工業區；地平線上還看得到觀音山、大崗山、小崗山與中央山脈。真實路網、行人、車流、紅綠燈，擬真車輛物理，日夜切換，手機傾斜或觸控轉向，進遊戲前可以用上帝視角俯瞰整座城市。

畫風預設是「插畫」：跟《偷花喵》同一套美術語言——深紫墨線描邊、平塗色塊、二丁掛磁磚、綠釉花磚、鐵窗、冷氣機、紅線、水溝蓋，夜晚窗戶與招牌會亮、路燈打出一圈圈光暈。路上的轎車、計程車、警車、小貨車、公車、砂石車、機車騎士，以及十六種行人（阿伯、阿嬤、上班族、學生、外送員、工人、觀光客、警察……）也都是同一套畫風。設定裡可以切回原本的「像素 HD-2D」。

像 GTA 一樣可以下車：停車後按「下車」就能走路（左手搖桿，推到底用跑的），「打」會自動對準最近的人，「上車」離幾步遠時主角會自己跑過去。路邊停著或等紅燈的車都能搶（轎車、計程車、警車、公車、砂石車、機車都行），司機會被拉下來跑掉。撞車會讓車子受損：冒煙、沒力，撞太多次引擎就掛了；路上的車被撞壞也會停在路邊冒黑煙。暫停選單可以「叫一台新車」。

**線上玩：** https://gajuioredvmn.github.io/kaohsiung-drive/

## 開發

```
python3 build.py      # 把 src/ 串成單一檔案：dist/index.html（發布用）與 test/index.html（本機測試）
cp dist/index.html index.html   # 根目錄的 index.html 就是 GitHub Pages 上線的版本
```

- `src/js/` 依檔名順序串接成一個 IIFE；`src/head.html`、`src/body.html` 是頁面骨架。
- `vendor/three.global.js` 是內嵌的 three.js（r169），不需要網路載入。
- `android/` 是 WebView 外殼；APK 只在 Actions 手動執行 `android` workflow 時建置。

## 操作

- 油門／煞車在右側，傾斜手機或左下滑桿轉向，畫面上方拖曳可轉鏡頭。
- 設定裡可以開關任務（小黃、外送、計時賽）與警察。

純原創美術與音效，沒有使用任何真實車廠名稱或受版權保護的素材。
